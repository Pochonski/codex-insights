# Security policy

Do not report vulnerabilities in public Issues or pull requests. Do not send credentials, `auth.json`, session logs, databases, or full conversation content.

Use the repository's **Security → Report a vulnerability** private advisory flow. Include the affected version, impact, and minimal reproduction steps with sensitive values removed. If the private reporting option is unavailable, contact the repository maintainer privately through their GitHub profile to arrange a secure channel before sharing details.

The supported version is the latest v0.3.x pre-release. Security fixes will be documented in a tagged release after validation.
